# 표류여행

텍스트 항해 게임. `index.html` 하나로 혼자서도 돌아가고, 서버를 붙이면 **초대받은 사람끼리 같은 바다**에서 즐길 수 있다.

## 혼자 하기 (서버 없음)
`index.html`만 열거나 정적 사이트로 올리면 된다. 저장은 브라우저에만 된다. 서버가 없으면 온라인 기능은 저절로 꺼진다.

## 다인 서버
- 초대 코드로만 가입 → 아이디·비밀번호로 로그인. 저장 파일이 계정에 보관돼 어느 기기에서든 이어 할 수 있다.
- **마주침**: 같은 바다에서 가까워지거나 같은 부두에 닿으면 서로 보인다. 인사와 거래(맡김 방식)를 할 수 있다.
- **병 편지**: 띄운 병은 다른 플레이어가 줍고 답장을 보낼 수 있다. 줍는 사람이 없을 때를 위해 NPC 병 편지는 그대로 남아 있다.
- **채팅**: 월드 채팅, 그리고 내 배(선장·선원) 채팅.
- **선원 시점**: 선장이 아이디로 초대 → 수락하면 타이틀에서 '선원으로 탑승'. 선원은 낚시·식사 준비·망보기·수리를 하고(선장이 오프라인이어도 쌓였다가 선장이 돌아오면 반영), 월급이 쌓여 자기 항해에서 찾을 수 있다.

서버는 Node 22 + 내장 SQLite뿐이라 `npm install`이 필요 없다. 접속자가 5초마다 한 번 동기화(폴링)하는 방식이라 서버가 가볍다.

### 실행
```
ADMIN_KEY=원하는비밀번호 node server/server.js      # http://localhost:3000
```
- 초대 코드 만들기: `http://서버/admin` 에서 ADMIN_KEY 입력 후 '만들기', 또는 서버 셸에서 `node server/cli.js invite 3 친구들`
- 데이터는 `DATA_DIR`(기본 `./data`)의 `adrift.db` 한 파일. 백업은 이 파일만 복사하면 된다.
- 점검: `node --test server/test.mjs`

### 배포와 비용 (가장 싸게)
SQLite 파일이 남아야 하므로 **디스크(볼륨)가 붙는 곳**이어야 한다. 무료 웹 서비스(예: Render 무료)는 잠들고 디스크가 없어 계정이 사라진다.
- **Fly.io** (`fly.toml`, `Dockerfile` 포함): 접속이 없으면 머신이 꺼지게 해 둬서 보통 월 몇 달러 안쪽.
- **Render** (`render.yaml`): 디스크가 붙는 starter 플랜 필요(월 정액).
- 개인 VPS에서 `node server/server.js`를 돌려도 된다.
가격은 바뀌니 배포 전에 각 서비스의 현재 요금을 확인할 것.

환경변수: `ADMIN_KEY`(필수에 가까움, 없으면 관리자 기능 꺼짐), `PORT`, `DATA_DIR`, `ENCOUNTER_RADIUS`(마주침 거리, 기본 2.5), `TRUST_PROXY=0`(프록시 뒤가 아닐 때).

### 알아 둘 점
- 게임 계산은 각자 브라우저에서 돈다. 서버는 계정·위치·우편·거래·채팅만 맡는다. 그래서 친구끼리 노는 용도로는 충분하지만, 클라이언트를 고쳐 소지품을 속이는 걸 완전히 막지는 못한다.
- 선원 보상(낚시 결과 등)은 서버가 정하고, 월급은 하루 200G까지다.
